DEL 4 — DE SIDSTE TESTS (E2E — kræver kørende site)
----------------------------------------------------------
14. Seer-status E2E:
    - Kort på /da/profile: "Du har set X minutter" — X skal
      være = eller større end "Din støtte" (større er
      FORVENTET pga. verdict-split).
    - SQL grund-sandhed:
      select floor(sum(watched_seconds)/60) from public.view_sessions
      where user_id = '<din-id>' and status <> 'active'
        and watched_seconds > 0;   → skal matche kortet.
    - Genre-række: top-genre + minutter i genren.
    - /en/profile: Curious / Pioneer / Legend + "{genre} nerd".
    - Frisk konto / 0 min: kun teaser-linjen, ingen titel.
15. @ tag E2E (parkerede tests):
    - Prefill-F5-test (gammel fane-teori).
    - Reserverede ord (@apply, @studio) afvises.
    - Syntaks (@ab, @Foo_Bar) afvises.
    - Kontosletning rydder handle og alt andet (cascade).
16. Generelle sidste tests: køb-flow, afspiller, upload,
    kommentarer — alt det, der skal være perfekt pr. lancering.
    - HERIBLANDD (opdaget 11/10): HÅNDHÆV 2 GB-grænsen — den er
      i dag kun tekst i fileLabel ("maks 2 GB"), ingen kode
      måler størrelsen. Ét klient-tjek (File.size ved filvalg,
      ved siden af mp4-tjekket) + ét server-tjek i POST
      /api/films (content-length fra den HEAD, der alligevel
      hentes til egress-estimatet) → afvis over 2 GB.
      720p forbliver VEJLEDNING (ikke håndhævet): 2 GB-taget
      disciplinerer bitraten naturligt, og hård 720p-mur ville
      blokere fremtidig Bunny-adaptive (1080p-upload).
    - HERIBLANDD: skaber-siden — udbetalingsoplysninger gemmes,
      udbetalingsanmodning under/over 150 kr-grænsen opfører
      sig rigtigt (afvis under, opret over).
